# ✅ Todo List

A simple and clean **Todo List application** built with **Vite, React, TypeScript, and Firebase Hosting**.  
Create, search, complete, and delete tasks with persistent local storage.

### 🔗 Live Demo
👉 https://todolist-vm.web.app

---

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Search through tasks
- 💾 Persistent data using **LocalStorage**
- 📱 Responsive layout
- ⚡ Fast build & dev experience with **Vite**

---

## 🛠 Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Bootstrap, CSS
- **Icons:** react-icons
- **Hosting:** Firebase Hosting
- **CI/CD:** GitHub Actions (auto-deploy)

### Install & Run Locally
